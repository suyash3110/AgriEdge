# AgriEdge local release — 15 September 2026

## Start without Codex

Double-click `Start AgriEdge.cmd` in the project root. The hidden supervisor runs the application on http://127.0.0.1:3001, restarts it after a process exit, and writes operational logs to `work/service/app.log`. The local database is `work/nagpur-preview`. Keep the PC running. This launcher does not depend on a Codex conversation or schedule automatic Windows logon startup.

`npm run build` prepares the release. Close the running application process before rebuilding its standalone files. `scripts/start.mjs` loads `.env.local`, prepares the local database, configures the project Python runtime, and starts the local voice model independently of HTTP startup.

## Tolerance

Buyer or seller proposes an absolute extra INR-per-quintal allowance with a reason on Transactions. Only the opposite party can accept or reject it. Acceptance replaces the previous allowance rather than accumulating it. The agreement rate and total are updated with integer paise arithmetic. Changes are forbidden once a payment order exists. Proposals, decisions and notifications remain in the database and audit trail.

## Gemini and market observations

The key is stored only in ignored `.env.local`. Gemini is the first-choice assistant provider; a separately started local language model is the fallback. Search-grounded price retrieval requires provider quota. The supplied key passed a text-generation test, but repeated Google Search grounding requests returned HTTP 429 RESOURCE_EXHAUSTED. Live price availability remains blocked on Google quota/billing, not on a generated forecast.

Fresh market results require source matching, positive INR/quintal values, Nagpur district and an observation date no older than seven days. Refreshes run in the background with a one-hour cache and five-minute retry cooldown. During provider outages, older CSV records retain their actual observation dates; they are not relabelled as live.

## Image model verification

Tomato was retrained from 7,224 supplied images with filename and exact-image grouping and train/validation/test separation. Twelve epochs reproduced the deployed checksum and held-out macro F1 of 0.8574966635191801. Therefore the existing identical model remains connected, with the rerun retained under `work/models-candidate/tomato`.

Existing local appearance models cover tomato, potato, rice/paddy and groundnut. Their class predictions are mapped to provisional A/B/C appearance grades. Plant-disease, species-identification and onion-seed datasets are not interchangeable with grain sale-grade labels; unsupported grain-quality cases still require an FPO assessment. Gemini API access is not training on these datasets. No newly trained universal crop-grading model is claimed.
